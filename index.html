✨ Features

Why TotallyNormalImage?

A comprehensive steganography solution built with security and usability in mind.

🔒

AES-256 Encryption

Optional password protection using industry-standard AES-256 encryption before LSB embedding for double-layered security.

📁

Hide Any File

Conceal any file type — PDFs, ZIPs, documents, executables — inside an ordinary-looking image. No file type restrictions.

🌐

100% Client-Side

All processing happens in your browser. No data is ever uploaded to any server — your secrets stay with you.

👁️

Visually Undetectable

LSB modification changes pixel values by at most ±1, making the encoded image indistinguishable from the original.

📱

Fully Responsive

Works seamlessly on desktops, tablets, and mobile devices. Steganography on the go.

⚡

Lightning Fast

Optimized pixel manipulation using HTML5 Canvas API for real-time encoding and decoding.

📚

Educational

Built-in interactive demos and explanations to help you understand how LSB steganography works.
